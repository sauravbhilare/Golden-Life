# Golden-Life
Golden Life is a mobile application designed specifically for people aged 50 and above, providing entertainment and updates about organized events tailored for them.  This web application serves as the backend management system for the mobile app. It allows administrators to:  Add, edit, view, and delete users  Manage payments and subscriptions  Upload and manage banner images, reels, and folders  Perform all CRUD (Create, Read, Update, Delete) operations related to app content  In summary, the web app is used to manage and control the content and users of the Golden Life Android application.
